# Amazon-Clone- Project


This is a clone of the Amazon e-commerce website built to showcase my web development skills. The project includes a responsive UI and interactive elements, mimicking key features of Amazon.

Features:

Responsive Navbar: Includes search functionality, user account options, cart, and navigation links.

Hero Section: A message banner with options to navigate between regions (e.g., Amazon India).

Shopping Categories: Display sections for clothing, electronics, and personal care.


Technologies Used:

HTML5

CSS3

Font Awesome Icons

Installation:

1. Clone the repository:

git clone https://github.com/BabuShaik778/amazon-clone.git

2. Navigate to the project directory:

cd amazon-clone

3. Open index.html in your browser to view the project.


Project Structure:

amazon-clone/  
├── index.html        # Main HTML file  
├── style.css         # CSS file for styling  
├── /image            # Folder for image 
└── README.md         # Project documentation
